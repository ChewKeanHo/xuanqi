## 核心理念

[![XuanQi](src/icons/animated-banner_1200x100.svg)](#)

此項目源於重獲內容生產控制權與簡潔性的需求：

1.  **您掌握絕對控制權** - 不再有投入後條款、條件或商業政策的意外的得意更變。
2.  **最大程度的可定制性** - 通過編程方式構建內容，擺脫限制性抽象假設和供應商鎖
    定流程的困擾。
3.  **去中心化供應鏈** - 完全擺脫地緣政治滋擾和愚蠢限制。
4.  **固有的模組化** - 以由各種技術構建的外部組件和資源簡單化管理工作。
5.  **可靠的復現能力** - 無論是單個`.pdf`文件、整個靜態頁面網站、網頁、圖像
    等等， 在任何時間和任何地點都可以可靠地復現任何內容。
6.  **極低學習成本** - 重用您的`POSIX Shell`腳本知識就行了。無需新的編程語言。
7.  **易於集成** - 僅需1條簡單命令即可與任何CI集成。




## 主要特性

[![XuanQi](src/icons/animated-banner_1200x100.svg)](#)

玄器目前能夠處理各種與內容生成相關的任務。讓我們一一探討究竟！

### 靜態網站生成（SSG）

*   **使用整個代碼庫** -  無需為了迎合SSG生成器的繁瑣限制而預先複製文件資源。
*   **無縫的輸出結構** - 使用簡單的操作系統文件系統路徑來映射整個站點，
    無需複雜或專有的數據庫解析。
*   **極高的可定制性** - 每個文件都由其自己的`Shell`腳本處理。您可以自由決
    定生產調用。
*   **無輸出限制** - 沒有內部SSG生成器的限制性約束。您和您的發布提供商可以自由
    決定。
*   **拒絕"萬事通，樣樣鬆"的劣質"功能** - 直接集成並使用專用工具，如運用`GIMP`
    來處理圖像和`FFPMEG`來處理音視頻。
*   **優化搜索引擎(SEO)輔助** - 通過玄器的可選SEO輔助功能，輕鬆滿足SEO要求。
*   **進化性的網站App(PWA)輔助** - 使用玄器的可選PWA輔助功能來輕鬆地將把網站轉換
    為 PWA 網絡應用。
*   **WebAssembly (WASM)輔助** - 使用玄器的可選WASM集成功能，準備將WASM嵌入或
    集成到您的"超級HTML"裏。

### 超级`HTML`

*   **零依賴** - 所有內容資源都嵌入到一個單一的超級HTML文件裏，可在任何有瀏
    覽器的環境下運行。
*   **`PDF`輸出輔助** - 準備使用無頭瀏覽器打印生產將"超級`HTML`"轉換為`PDF`
    （註：您需自帶符合打印要求的`CSS`樣式表）。
