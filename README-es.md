*Domina el Caos de la Producción de Contenidos.*

Infierno de dependencias, cadenas de herramientas frágiles, problemas de
seguridad, complejidades geopolíticas — estos no deberían perturbar tu
flujo de trabajo. XuanQi ofrece una alternativa poderosa: software altamente
portable y personalizable que garantiza la reproducción confiable y
consistente de tu contenido en cualquier momento y lugar.

Basado en los principios de consistencia, cadenas de suministro
descentralizadas y simplicidad, XuanQi asegura una verdadera soberanía de
datos. Tus datos y su procesador de producción permanecen reproducibles y
mantenibles, sin introducir dependencias críticas o comprometer el desarrollo
futuro.

**XuanQi - Crea contenidos de forma fluida y sencilla.**




## Por qué es importante

[![XuanQi](src/icons/animated-banner_1200x100.svg)](#)

Este proyecto nace de la necesidad de recuperar el control y la simplicidad
en la producción de contenidos:

1.  **Mantienes el Control Absoluto** - No más cambios sorpresa en términos,
    condiciones o políticas comerciales después de tu inversión.
2.  **Máxima Personalización** - Construye contenido programáticamente,
    libre de suposiciones abstractas restrictivas y procesos de bloqueo de
    proveedores.
3.  **Cadenas de Suministro Descentralizadas** - Opera libre de molestias
    geopolíticas y restricciones irracionales.
4.  **Modularidad Innata** - Gestiona fácilmente componentes y recursos
    externos construidos con diversas tecnologías.
5.  **Capacidad de Reproducción Confiable** -  Reproduce de manera confiable
    cualquier contenido, desde un simple archivo `.pdf` hasta un sitio web
    completo de páginas estáticas, en cualquier momento y lugar.
6.  **Costo de Aprendizaje Muy Bajo** - Reutiliza tu conocimiento de scripts
    `POSIX Shell`. No se requieren nuevos lenguajes de programación.
7.  **Fácil Integración** - Solo se necesita 1 comando simple para integrarse
    con cualquier `CI`.




## Características Principales

[![XuanQi](src/icons/animated-banner_1200x100.svg)](#)

XuanQi es actualmente capaz de manejar diversas tareas relacionadas con la
generación de contenido. ¡Explorémoslas una por una!



### Generación de Sitios Estáticos (SSG)

*   **Utiliza Todo el Repositorio** - No es necesario duplicar previamente
    recursos para adaptarse a las limitaciones tediosas del generador SSG.
*   **Estructura de Salida Fluida** - Mapea todo el sitio usando simples rutas
    del sistema de archivos del SO, sin necesidad de análisis de bases de datos
    complejas o propietarias.
*   **Altamente Personalizable** - Cada archivo es procesado por su propio
    script `Shell`. Tú decides libremente la llamada de producción.
*   **Sin Restricciones de Salida** - Sin las restrictivas limitaciones del
    generador `SSG` interno. Tú y tu proveedor de publicación deciden
    libremente.
*   **Rechaza "Funcionalidades" Mediocres de "Aprendiz de Todo, Maestro de
    Nada"** - Integra y utiliza directamente herramientas especializadas, como
    `GIMP` para procesamiento de imágenes y `FFMPEG` para audio y video.
*   **Asistencia de Optimización de Motores de Búsqueda (SEO)** - Cumple
    fácilmente con los requisitos SEO mediante las funciones opcionales de
    asistencia SEO de XuanQi.
*   **Asistencia para Aplicaciones Web Progresivas (PWA)** - Utiliza las
    funciones opcionales de asistencia PWA de XuanQi para convertir fácilmente
    tu sitio web en una aplicación web PWA.
*   **Asistencia WebAssembly (WASM)** - Utiliza las funciones opcionales de
    integración WASM de XuanQi para embeber o integrar WASM en tu "Súper
    `HTML`".



### Súper `HTML`

*   **Cero Dependencias** - Todos los recursos de contenido están incrustados
    en un único archivo súper `HTML` que se ejecuta en cualquier entorno con
    navegador.
*   **Asistencia para Salida `PDF`** - Prepárate para convertir el
    "Súper `HTML`" a `PDF` usando la impresión con navegador headless (Nota:
    necesitas tu propia hoja de estilo `CSS` compatible con impresión).
