*コンテンツ生産の混沌を制御する。*

依存地獄、脆弱なツールチェーン、セキュリティリスク、地政学的複雑さ —— これらが
あなたのワークフローを妨げるべきではありません。玄器は強力な代替案を提供しま
す：高い移植性、あらゆる時間、あらゆる場所で信頼性の高い、カスタマイズ可能な
ソフトウェアで一貫してあなたのコンテンツを再現します。

玄器は、一貫性、分散化サプライチェーン、シンプルさの原則に基づいて真のデータ
主権を確保します。あなたのデータとその生産プロセッサーは、重要な依存関係を導
入したり将来の発展を損なうことなく、再現可能で維持可能な状態を保ちます。

**玄器 – シームレスで簡単、創作に集中。**




## 核心理念

[![XuanQi](src/icons/animated-banner_1200x100.svg)](#)

このプロジェクトは、コンテンツ生産の制御権とシンプルさを取り戻す必要性から生
まれました：

1. **あなたが絶対的なコントロールを握る** - 投資後の条項、条件、ビジネスポリシ
   ーの予期せぬ変更はもうありません。
2. **最大限のカスタマイズ性** - プログラムでコンテンツを構築し、制限的な抽象的
   な仮定とベンダーロックインのプロセスから解放されます。
3. **分散化サプライチェーン** - 地政学的な問題や愚かな制限から完全に自由になり
   ます。
4. **本質的なモジュール性** - 様々な技術で構築された外部コンポーネントとリソー
   スの管理を簡素化します。
5. **信頼性の高い再現能力** - 単一の`.pdf`ファイル、完全な静的ページウェブサイ
   ト、ウェブページ、画像など、あらゆるコンテンツをあらゆる時間と場所で確実に
   再現できます。
6. **非常に低い学習コスト** - あなたの既存の`POSIX Shell`スクリプトの知識を再
   利用するだけです。新しいプログラミング言語は必要ありません。
7. **簡単な統合** - たった1つの簡単なコマンドで、あらゆる`CI`と統合できます。




## 主な機能

[![XuanQi](src/icons/animated-banner_1200x100.svg)](#)

玄器は現在、様々なコンテンツ生成関連のタスクを処理できます。一つずつ詳しく見
ていきましょう！



### 静的サイト生成（SSG）

*   **リポジトリ全体を使用** - SSGジェネレーターの煩わしい制限に合わせてファ
    イルリソースを事前に複製する必要はありません。
*   **シームレスな出力構造** - シンプルなOSファイルシステムのパスを使用してサ
    イト全体をマッピングし、複雑なまたは独自のデータベース解析は必要ありません。
*   **非常に高いカスタマイズ性** - 各ファイルは独自の`Shell`スクリプトで処理さ
    れます。あなたは自由にプロダクションコールを決定できます。
*   **出力制限なし** - 内部のSSGジェネレーターによる制限的な制約はありません。
    あなたとあなたの公開プロバイダーは自由に決定できます。
*   **「何でも屋、どれも中途半端」な低品質「機能」を拒否** - なんでも屋の妥協
    はもう終わり。画像処理に`GIMP`、メディア処理に`FFmpeg`といった専用ツールを
    シームレスに組み込めます。
*   **検索エンジン最適化(SEO)サポート** - 玄器のオプションのSEOサポート機能を
    通じて、SEO要件を簡単に満たします。
*   **プログレッシブウェブアプリ(PWA)サポート** - 玄器のオプションのPWAサポー
    ト機能を使用して、サイトを簡単にPWAウェブアプリに変換します。
*   **WebAssembly (WASM)サポート** - 玄器のオプションのWASM統合機能を使用して、
    WASMをあなたの「スーパーHTML」に埋め込んだり統合したりする準備ができていま
    す。



### スーパー`HTML`

*   **ゼロ依存** - すべてのコンテンツリソースは単一のスーパー`HTML`ファイルに
    埋め込まれており、ブラウザが動作する環境ならどこでも実行できます。
*   **`PDF`出力サポート** - ヘッドレスブラウザの印刷機能を使用して
    「スーパー`HTML`」をPDFに変換します（注：印刷に適した`CSS`スタイルシート
    を自分で準備する必要があります）。
