XUANQI_COMPONENT_NAME
This configuration is for accessing XuanQi's specific component
name. The name is a relative path used to for forming the
`$XUANQI_COMPONENT_PATH` which points to the component's root
directory path.

When set, it means the component is already been found inside
`$XUANQI_DIRECTORY_COMPONENTS` where its directory path is defined
in `$XUANQI_PATH_COMPONENTS`.

         >>>> **DO NOT MODIFY OR OVERRIDE** <<<<
         This is an internal system configuration.

The value is determined automatically on app initialization
depending on functions (e.g. `create component` or `build`).

It contains the relative path to the $XUANQI_PATH_COMPONENTS`.
