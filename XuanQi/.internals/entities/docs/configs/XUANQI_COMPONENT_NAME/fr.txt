XUANQI_COMPONENT_NAME
Cette configuration permet d'accéder au nom spécifique du
composant XuanQi. Le nom est un chemin relatif utilisé pour
former la `$XUANQI_COMPONENT_PATH` qui pointe vers le chemin
du répertoire racine du composant.

Lorsqu'il est défini, cela signifie que le composant a déjà
été trouvé dans `$XUANQI_DIRECTORY_COMPONENTS` où son chemin
de répertoire est défini dans `$XUANQI_PATH_COMPONENTS`.

      >>>> **NE PAS MODIFIER NI REMPLACER** <<<<
    Il s'agit d'une configuration interne du système.

La valeur est déterminée automatiquement lors de l'initialisation
de l'application en fonction des fonctions (ex. `create component`
ou `build`).

Elle contient le chemin relatif vers `$XUANQI_PATH_COMPONENTS`.
