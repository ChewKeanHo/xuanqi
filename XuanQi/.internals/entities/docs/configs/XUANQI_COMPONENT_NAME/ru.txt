XUANQI_COMPONENT_NAME
Эта конфигурация предназначена для доступа к определенному
имени компонента XuanQi. Имя представляет собой относительный
путь, используемый для формирования `$XUANQI_COMPONENT_PATH`,
который указывает на путь к корневой директории компонента.

Когда установлено, это означает, что компонент уже найден внутри
`$XUANQI_DIRECTORY_COMPONENTS`, где его путь к директории определен
в `$XUANQI_PATH_COMPONENTS`.

       >>>> **НЕ ИЗМЕНЯЙТЕ И НЕ ПЕРЕОПРЕДЕЛЯЙТЕ** <<<<
            Это внутренняя системная конфигурация.

Значение определяется автоматически при инициализации приложения
в зависимости от функций (например, `create component` или `build`).

Оно содержит относительный путь к `$XUANQI_PATH_COMPONENTS`.
