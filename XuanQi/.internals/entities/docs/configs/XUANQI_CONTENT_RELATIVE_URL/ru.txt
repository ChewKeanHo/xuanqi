XUANQI_CONTENT_RELATIVE_URL
Эта конфигурация предназначена для идентификации выходного файла
с использованием относительной маршрутизации `router`.

        >>>> **НЕ ИЗМЕНЯЙТЕ И НЕ ПЕРЕОПРЕДЕЛЯЙТЕ** <<<<
             Это внутренняя системная конфигурация.

Значение определяется автоматически при инициализации `router`.
Оно предназначено для обработки значений.

Для работы в качестве URL используйте вместо этого $XUANQI_CONTENT_URL.

Для работы в качестве пути файловой системы используйте вместо
этого $XUANQI_CONTENT_PATH.
