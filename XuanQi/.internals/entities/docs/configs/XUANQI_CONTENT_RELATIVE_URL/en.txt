XUANQI_CONTENT_RELATIVE_URL
This configuration is for identifying the output file using the
`router`'s relative pathing.

            >>>> **DO NOT MODIFY OR OVERRIDE** <<<<
           This is an internal system configuration.

The value is determined automatically on `router` initialization.
It is designed for value processing.

To operate as URL, use $XUANQI_CONTENT_URL instead.

To operate as a filesystem pathing, use $XUANQI_CONTENT_PATH instead.
