XUANQI_COMPONENT_PATH
Cette configuration permet d'accéder au répertoire spécifique
du composant XuanQi dérivé de `$XUANQI_COMPONENT_NAME`.

Quand elle est définie, cela signifie que le composant a déjà
été trouvé dans `$XUANQI_DIRECTORY_COMPONENTS` où son chemin de
répertoire est défini dans `$XUANQI_PATH_COMPONENTS`.

        >>>> **NE PAS MODIFIER NI REMPLACER** <<<<
      Il s'agit d'une configuration interne du système.

La valeur est déterminée automatiquement lors de l'initialisation
de l'application en fonction des fonctions (ex. `create component`
ou `build`).

Elle contient le chemin absolu vers le composant spécifique.
