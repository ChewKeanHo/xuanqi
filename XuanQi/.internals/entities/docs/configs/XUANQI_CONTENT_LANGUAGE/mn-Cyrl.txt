XUANQI_CONTENT_LANGUAGE
Энэ тохиргоо нь гарах файлын хэлийг тохируулах зорилготой. Энэ нь
router файлаар тохируулагдаж, component-ийн render importer shell
script-руу дамжуулдаг.

Тогтвортой байх үүднээс утга нь дараах форматыг дагах
BCP 47 locale code байхыг зөвлөж байна:

                 `[ХЭЛ]{-[СКРИПТ]}{-[УЛС]}`
Энд:
        * `[ХЭЛ]`        - ISO639 хэлний код.
        * `{-[СКРИПТ]}`  - ISO15924 хэлний бичлэгийн скрипт
                           (заавал биш). зураас `-` ялгагч
                           угтагдаж, `{ }` бүслүүр орохгүй.
        * `{-[УЛС]}`     - ISO3166 улсын код (заавал биш).
                           зураас `-` ялгагч угтагдаж,
                           `{ }` бүслүүр орохгүй.
Жишээ:
        * `en`           - Олон Улсын Англи Хэл
        * `zh-Hans`      - Олон Улсын Хялбарбичсэн Хятад Хэл
        * `zh-Hant`      - Олон Улсын Уламжлалт Хятад Хэл
        * `zh-Hans-US`   - Америк Нэгдсэн Улсын Хялбарбичсэн Хятад Хэл
        * `zh-Hant-US`   - Америк Нэгдсэн Улсын Уламжлалт Хятад Хэл
        * `zh-Hans-MY`   - Малайзын Хялбарбичсэн Хятад Хэл
        * `zh-Hant-MY`   - Малайзын Уламжлалт Хятад Хэл

Утгын бэлэн байдал нь зөвхөн router файлаас хамаарна.
Хэрэв тохируулагдсан бол бэлэн байна. Утга нь албадах биш.
Component нь ямар ч утгыг шалгаж, үүний дагуу
ажиллах бүрэн үүрэг хүлээх ёстой.
