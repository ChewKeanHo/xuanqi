XUANQI_CONTENT_URL
Эта конфигурация предназначена для настройки URL целевого выходного
контента для веб-приложений. Этот URL представляет собой абсолютный
путь к файлу, построенный с использованием $XUANQI_CONTENT_BASE_URL
и относительного пути к файлу его скрипта `router`.

         >>>> **НЕ ИЗМЕНЯТЬ И НЕ ПЕРЕОПРЕДЕЛЯТЬ** <<<<
             Это внутренняя системная конфигурация.

Значение определяется автоматически при инициализации `router`. Оно
предназначено для записи контента. Для работы в качестве пути
файловой системы используйте вместо этого $XUANQI_CONTENT_PATH.
