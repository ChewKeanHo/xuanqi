XUANQI_CONTENT_URL
This configuration is for configuring the targeted output content's
URL for web-based application. This URL is in absolute filepath
constructed using the $XUANQI_CONTENT_BASE_URL and the relative
filepath of its `router` script.

            >>>> **DO NOT MODIFY OR OVERRIDE** <<<<
           This is an internal system configuration.

The value is determined automatically on `router` initialization.
It is designed for content writing. To operate as a filesystem
pathing, use $XUANQI_CONTENT_PATH instead.
