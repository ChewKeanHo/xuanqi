XUANQI_CONTENT_URL
Esta configuración es para configurar la URL del contenido de salida
destinado para aplicaciones web. Esta URL es una ruta de archivo
absoluta construida usando $XUANQI_CONTENT_BASE_URL y la ruta de
archivo relativa de su script `router`.

          >>>> **NO MODIFICAR NI SOBREESCRIBIR** <<<<
         Esta es una configuración interna del sistema.

El valor se determina automáticamente en la inicialización del
`router`. Está diseñado para escritura de contenido. Para operar
como una ruta del sistema de archivos, use $XUANQI_CONTENT_PATH en
su lugar.
