XUANQI_CONTENT_URL
Cette configuration permet de configurer l'URL du contenu cible
pour les applications Web. Cette URL est un chemin de fichier absolu
construit en utilisant $XUANQI_CONTENT_BASE_URL et le chemin relatif
du script `router`.

            >>>> **NE PAS MODIFIER NI REMPLACER** <<<<
          Il s'agit d'une configuration système interne.

La valeur est déterminée automatiquement à l'initialisation du
`router`. Elle est conçue pour l'écriture de contenu. Pour fonctionner
comme un chemin de système de fichiers, utilisez $XUANQI_CONTENT_PATH
à la place.
