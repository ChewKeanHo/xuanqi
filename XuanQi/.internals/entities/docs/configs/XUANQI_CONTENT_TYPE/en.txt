XUANQI_CONTENT_TYPE
This configuration is to set the output file's MIME type.
This is configured by the router file and delivering into a
component's rendering importer shell script. Examples:

* 'font/woff', 'font/tff', and 'font/otf'    - fonts
* 'image/png', 'image/svg+xml', 'image/avif' - images
* 'text/plain'                               - text
* 'video/mp4', 'video/webm'                  - video
* 'application/octet-stream'                 - binary file

The value's availability depends on the router file alone.
If it is set, then it is available. The value is not enforced.
It is the component's full responsibility to check and to react
any value accordingly.

Reference:

1. https://developer.mozilla.org/en-US/docs/Web/HTTP/Guides/MIME_types
