Dies ist eine Dokumentationsvorlage, die Ihre untenstehende Konfiguration
beschreibt. Sie sollte erklären, was genau dies ist und welchen Zweck es
erfüllt.

Der zweite Absatz erläutert hier, welche Konsequenzen diese Einstellung
verursacht hat. Optional können Sie hier erklären, wie es funktioniert.

Der dritte Absatz erläutert hier, welche Werte es annehmen kann. Sie
können hier den Kommentar 'VARIABLE_NAME' hinzufügen, für den Fall, dass
der Benutzer sich von fehlgeschlagenen Experimenten erholen muss,
zusammen mit einem 'Empfohlenen Wert'.
