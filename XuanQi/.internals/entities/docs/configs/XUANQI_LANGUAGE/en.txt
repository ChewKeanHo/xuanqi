XUANQI_LANGUAGE
This configuration is set XuanQi's main operational
and fallback language. This can be configured from
CLI or from a configuration file inside
`$XUANQI_DIRECTORY_CONFIGS` directory.

The value is a BCP 47 locale code complying to the
following format:

        `[LANG]{-[SCRIPT]}{-[COUNTRY]}`
where:
        * `[LANG]`       - ISO639 language code.
        * `{-[SCRIPT]}`  - optional ISO15924 language script
                           with a dash `-` prefix separator and
                           without the `{ }` braces.
        * `{-[COUNTRY]}` - optional ISO3166 country code
                           with a dash `-` prefix separator and
                           without the `{ }` braces.
Examples:
        * `en`           - International English
        * `zh-Hans`      - International Simplified Chinese
        * `zh-Hant`      - International Traditional Chinese
        * `zh-Hans-US`   - United States Simplified Chinese
        * `zh-Hant-US`   - United States Traditional Chinese
        * `zh-Hans-MY`   - Malaysia's Simplified Chinese
        * `zh-Hant-MY`   - Malaysia's Traditional Chinese

The priority is as follows with the latter overwriting the
former:

1. Parse environment language variables (e.g. `$LANG`). Set to
   `en` as default when failed.
2. Parse `$XUANQI_DIRECTORY_CONFIGS`. Fallback to `en` if fails.
3. command line overrides (e.g.
   `XUANQI_LANGUAGE=zh-hans [XUANQI] help`). Fallback to `en`
   if fails.
