XUANQI_LANGUAGE
Эта конфигурация устанавливает основной рабочий и резервный
язык XuanQi. Она может быть настроена через CLI или через файл
конфигурации в директории `$XUANQI_DIRECTORY_CONFIGS`.

Значение представляет собой код локали BCP 47, соответствующий
следующему формату:

             `[ЯЗЫК]{-[ПИСЬМЕННОСТЬ]}{-[СТРАНА]}`
где:
        * `[ЯЗЫК]`            - код языка ISO639.
        * `{-[ПИСЬМЕННОСТЬ]}` - опциональный шрифт языка ISO15924
                                с разделителем в виде тире `-`
                                без фигурных скобок `{ }`.
        * `{-[СТРАНА]}`       - опциональный код страны ISO3166
                                с разделителем в виде тире `-`
                                без фигурных скобок `{ }`.

Примеры:
        * `en`           - Международный английский
        * `zh-Hans`      - Международный упрощенный китайский
        * `zh-Hant`      - Международный традиционный китайский
        * `zh-Hans-US`   - Упрощенный китайский (США)
        * `zh-Hant-US`   - Традиционный китайский (США)
        * `zh-Hans-MY`   - Малайзийский упрощенный китайский
        * `zh-Hant-MY`   - Малайзийский традиционный китайский

Приоритет следующий, где последующие значения
переопределяют предыдущие:

1. Разобрать переменные языка окружения (напр. `$LANG`). Установить
   `en` по умолчанию при сбое.
2. Разбор `$XUANQI_DIRECTORY_CONFIGS`. Откат на `en` при сбое.
3. Переопределения командной строки (напр.
   `XUANQI_LANGUAGE=zh-hans [XUANQI] help`). Откат на `en` при сбое.
