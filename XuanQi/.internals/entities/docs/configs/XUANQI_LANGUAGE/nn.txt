XUANQI_LANGUAGE
Denne konfigurasjonen set hovudoperasjons-og reserve-språket til
XuanQi. Det kan konfigurerast frå kommandolinje eller frå ei
konfigurasjonsfil i `$XUANQI_DIRECTORY_CONFIGS`-katalogen.

Verdien er ein BCP 47 lokal-kode som følgjer følgjande format:

                `[SPRÅK]{-[SKRIPT]}{-[LAND]}`
kor:
        * `[SPRÅK]`     - ISO639 språkkode.
        * `{-[SKRIPT]}` - valfri ISO15924 språkskript
                          med bindestrek `-` prefiksskiljeteikn
                          utan `{ }`-parentesane
        * `{-[LAND]}`   - valfri ISO3166 landkode
                          med bindestrek `-` prefiksskiljeteikn
                          utan `{ }`-parentesane

Døme:
        * `en`           - Internasjonal engelsk
        * `zh-Hans`      - Internasjonal forenkla kinesisk
        * `zh-Hant`      - Internasjonal tradisjonell kinesisk
        * `zh-Hans-US`   - Amerikansk forenkla kinesisk
        * `zh-Hant-US`   - Amerikansk tradisjonell kinesisk
        * `zh-Hans-MY`   - Malaysisk forenkla kinesisk
        * `zh-Hant-MY`   - Malaysisk tradisjonell kinesisk

Prioriteten er som følgjer, der sistnemnde overskriv førstnemnde:

1. Analyser miljøspråkvariable (t.d. `$LANG`). Sett til `en` som
   standard ved feil.
2. Analyser `$XUANQI_DIRECTORY_CONFIGS`. Fallback til `en` ved
   feil.
3. Kommandolinje-overstyringar (t.d.
   `XUANQI_LANGUAGE=zh-hans [XUANQI] help`). Fallback til `en`
   ved feil.
