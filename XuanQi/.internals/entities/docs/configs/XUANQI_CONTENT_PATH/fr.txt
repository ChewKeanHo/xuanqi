XUANQI_CONTENT_PATH
Cette configuration permet de créer le fichier cible avec son
emplacement exact en chemin de fichier absolu.

        >>>> **NE PAS MODIFIER NI REMPLACER** <<<<
       Il s'agit d'une configuration système interne.

La valeur est déterminée automatiquement lors de l'initialisation
du `router`. Elle est conçue pour l'écriture dans le système de
fichiers. Pour une utilisation comme URL, utilisez plutôt
$XUANQI_CONTENT_URL.
