# Создание раздела справки CSS компонента

Это раздел справки для создания CSS компонента либо
независимо, либо как часть другого большего компонента. Чтобы
включить CSS часть, просто введите `css` в значение `[TYPES]`.
Пример:

```
# шаблон команды
$ [XuanQi] create component [TYPES] [NAME]

# только CSS компонент
$ [XuanQi] create component css [NAME]

# с CSS частью внутри составного компонента
$ [XuanQi] create component "...,css,..." [NAME]
```




## Назначение

CSS компонент в основном предназначен для создания выходного
файла CSS ресурса (например, `page.css`). XuanQi имеет как
встроенные возможности в функциях `Shell`, так и копирование
обычного CSS файла.




## Структуры файлов

CSS компонент соответствует следующей структуре файлов по
умолчанию:

```
[XUANQI_PATH_COMPONENTS]
└── [XUANQI_COMPONENT_NAME]
       ├── CSS
       │    ├── sample.css
       │    ├── ...
       │    └── xuanqi.sh
       └── XuanQi
            └── import.sh
```

* директория компонента - `CSS`.
* shell-скрипт оператора компонента - `CSS/xuanqi.sh`.
* shell-скрипт оператора компонента вызывается основным скриптом
  импорта компонента `XuanQi/import.sh`.




## Основной скрипт `CSS/xuanqi.sh`

Ваша **конечная цель - записать выходной CSS файл
в `$XUANQI_CONTENT_PATH` своим способом**. Как это сделать, полностью
зависит от вас.

Несколько скриптов маршрутизаторов могут вызывать один и тот же
компонент для рендеринга файлов (например, разные медиа цели,
такие как мобильные, печать, электронная почта для одного и того же
контента). Поэтому вы должны стратегически спроектировать необходимые
переменные окружения для пользователей, чтобы настроить их в скрипте
маршрутизатора.

Затем, во время выполнения `CSS/xuanqi.sh`, проанализируйте эти
переменные окружения и реагируйте соответствующим образом.

Вы можете обратиться к `XuanQi/.internals/API` проекта для доступных
API.




## Программно или Копирование

XuanQi предоставляет как программируемые функции, так и функции
необработанного копирования для простого рендеринга CSS файла.
Решение зависит от вашей команды.

Если ваша команда не знакома с shell-скриптингом, предпочтительнее
последнее, чтобы вся команда могла работать с предоставленным файлом
`.css`, пока XuanQi просто копирует его в `$XUANQI_CONTENT_PATH`. Это
отлично подходит для тех, кто использует компилятор `Sass`.

Программируемые функции shell-скриптинга XuanQi обеспечивают большую
внутреннюю гибкость при рендеринге (думайте о макросах над написанием
CSS). Преимущество в отсутствии зависимостей и чрезвычайной гибкости
с вашим генератором контента. Это подходит для опытных разработчиков
CSS, которые считают `Sass` препятствием.

В любом случае, вы в хороших руках. Просто попробуйте и адаптируйтесь
со временем.
