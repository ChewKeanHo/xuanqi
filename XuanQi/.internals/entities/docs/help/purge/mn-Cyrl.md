# Purge CLI

`Purge` команд мөрний интерфейс (CLI) нь төслийн ажлын орчинг бүрэн
цэвэрлэхэд зориулагдсан.

Энэ нь дараах замуудыг устгадаг:

```
$XUANQI_PATH_LOGS       # өмнөх бүх билд логгууд
$XUANQI_PATH_PUBLIC     # бүх гаралтууд
$XUANQI_PATH_TEMPS      # өмнөх билдээс үүссэн түр файлууд
```

Чимээгүй цэвэрлэхээс ялгаатай нь энэ CLI нь бодит устгал хийхээс өмнө
зорилтот байгаа эсэхийг шалгадаг. Үгүй бол энэ CLI юу ч хийхгүй.




## Устгал мэдэгдэх

XuanQi нь бодитоор устгасан зорилтуудаа л мэдээлнэ.




## Эпилог

Энэ CLI-ийн талаар үүүр л боллоо.
