*驾驭内容生产的混沌。*

依赖地狱、脆弱的工具链、安全隐患、地缘政治复杂性 —— 这些不该骚扰你的工作流程。
玄器提供了一个强大的替代方案：高度便携、保证在任何时间、任何地点都能可靠、
可定制的软件一致地复现您的内容。

玄器在基于一致性、去中心化供应链和简洁性的原则确保了真正的数据主权。您的数据
及其生产处理器保持可复现和可维护，无需引入关键依赖或损害未来发展。

**玄器 – 轻松无缝，专注创作。**




## 核心理念

[![XuanQi](src/icons/animated-banner_1200x100.svg)](#)

此项目源于重获内容生产控制权与简洁性的需求：

1.  **您掌握绝对控制权** - 不再有投入后条款、条件或商业政策的意外的得意更变。
2.  **最大程度的可定制性** - 通过编程方式构建内容，摆脱限制性抽象假设和供应商锁
    定流程的困扰。
3.  **去中心化供应链** - 完全摆脱地缘政治滋扰和愚蠢限制。
4.  **固有的模块化** - 以由各种技术构建的外部组件和资源简单化管理工作。
5.  **可靠的复现能力** - 无论是单个`.pdf` 文件、整个静态页面网站、网页、图像
    等等， 在任何时间和任何地点都可以可靠地复现任何内容。
6.  **极低学习成本** - 重用您的`POSIX Shell`脚本知i识就行了。无需新的编程语言。
7.  **易于集成** - 仅需1条简单命令即可与任何`CI`集成。




## 主要特性

[![XuanQi](src/icons/animated-banner_1200x100.svg)](#)

玄器目前能够处理各种与内容生成相关的任务。让我们一一探讨究竟！

### 静态网站生成（SSG）

*   **使用整个代码库** - 无需为了迎合SSG生成器的繁琐限制而预先复制文件资源。
*   **无缝的输出结构** - 使用简单的操作系统文件系统路径来映射整个站点，
    无需复杂或专有的数据库解析。
*   **极高的可定制性** - 每个文件都由其自己的`Shell`脚本处理。您可以自由决
    定生产调用。
*   **无输出限制** - 没有内部`SSG`生成器的限制性约束。您和您的发布提供商可以自由
    决定。
*   **拒绝"万事通，样样松"的劣质"功能"** - 直接集成并使用专用工具，如运用`GIMP`
    来处理图像和`FFPMEG`来处理音视频。
*   **优化搜索引擎(SEO)辅助** - 通过玄器的可选SEO辅助功能，轻松满足SEO要求。
*   **进化性的网站App(PWA)辅助** - 使用玄器的可选PWA辅助功能来轻松地将把网站转换
    为 PWA 网络应用。
*   **WebAssembly (WASM)辅助** - 使用玄器的可选WASM集成功能，准备将WASM嵌入或
    集成到您的"超级`HTML`"里。

### 超级`HTML`

*   **零依赖** - 所有内容资源都嵌入到一个单一的超级`HTML`文件里，可在任何有浏
    览器的环境下运行。
*   **`PDF`输出辅助** - 准备使用无头浏览器打印生产将"超级`HTML`"转换为`PDF`
   （注：您需自带符合打印要求的`CSS`样式表）。
