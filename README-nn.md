*Tem kaoset i innhaldsproduksjonen.*

Avhengigheitshelvete, skjøre verktykjeder, tryggleiksproblem og geopolitiske
kompleksitetar—desse bør ikkje forstyrre arbeidsstraumen din. XuanQi tilbyr
eit kraftig alternativ: høgt portabel, tilpassingsvennleg programvare som
garanterer påliteleg og konsistent reproduksjon av innhaldet ditt,
kvar som helst og når som helst.

Bygd på prinsippa om konsistens, desentraliserte forsyningskjeder og enkelheit,
sikrar XuanQi ekte datasuverenitet. Dine data og produksjonsprosessoren deira
vert verande reproduserbare og vedlikehaldbare, utan å innføre kritiske
avhengigheiter eller kompromittere framtidig utvikling.

**XuanQi - Bygg innhaldet sømlaust og enkelt.**




## Kvifor det betyr noko

[![XuanQi](src/icons/animated-banner_1200x100.svg)](#)

Dette prosjektet oppstod frå behovet for å gjenvinne kontroll og enkelheit i
innhaldsproduksjon:

1.  **Du Halder Absolutt Kontroll** - Ingen overraskande endringar i vilkår,
    betingelsar eller forretningspolitikk etter at du har investert.
2.  **Maksimal Tilpassingsevne** - Bygg innhald programmatisk, fri frå
    restriktive abstrakte føresetnader og leverandørlåste prosessar.
3.  **Desentraliserte Forsyningskjeder** - Ver heilt fri frå geopolitiske
    forstyrringar og dumme avgrensingar.
4.  **Innbygd Modularitet** - Enkelt å administrere eksterne komponentar og
    ressursar bygde av ulike teknologiar.
5.  **Påliteleg Reproduksjonsevne** - Reproducer kva som helst innhald
    påliteleg, kvar som helst og når som helst, anten det er ei enkelt
    `.pdf`-fil, heile statiske nettsider, nettside, bilete, osv.
6.  **Veldig Låg Læringskostnad** - Bruk di eksisterande
    `POSIX Shell`-skriptkunnskap. Ingen nye programmeringsspråk naudsynt.
7.  **Enkel Integrering** - Berre 1 enkelt kommando naudsynt for integrering
    med kva som helst `CI`.




## Hovudfunksjonar

[![XuanQi](src/icons/animated-banner_1200x100.svg)](#)

XuanQi er i stand til å handsama ulike innhaldsgenereringsrelaterte oppgåver.
La oss utforska dei!



### Statisk Sidegenerering (SSG)

*   **Bruk Heile Repositoryet** - Ikkje naudsynt å førehandsduplisere
    filressursar berre for å tilfredsstilla eit SSG-generator sine plagsame
    avgrensingar.
*   **Sømlaus Output Struktur** - Bruk enkle OS-filsystems filstiar for å
    kartleggja heile nettstaden, utan komplisert eller proprietær
    databaseanalyse.
*   **Ekstremt Høg Tilpassingsevne** - Kvar fil vert handsama av sitt eige
    `Shell`-skript. Du tek fritt produksjonsbeslutninga.
*   **Ingen Output Avgrensningar** - Ingen interne SSG-generator restriktive
    avgrensningar. Du og din publiseringsleverandør kan fritt bestemma.
*   **Avvis "Master av Alt, Mester av Ingenting" Sub-par Kvalitets
    "Funksjonar"** - Integrer og bruk dedikerte verkty direkte, som å bruka
    `GIMP` for biletehandsaming og `FFMPEG` for lyd- og videohandsaming.
*   **Søkemotoroptimalisering (SEO) Assistanse** - Ver klar til å møta
    SEO-krav med XuanQi sine valfrie SEO-assistansefunksjonar.
*   **Progressiv Web App (PWA) Assistanse** - Bruk XuanQi sine valfrie
    PWA-assistansefunksjonar for enkelt å omdanna nettstaden din til ei PWA
    web app.
*   **WebAssembly (WASM) Assistanse** - Bruk XuanQi sine valfrie
    WASM-integrasjonsfunksjonar for å vera klar til å byggja inn eller
    integrera WASM i di "Super `HTML`".



### Super `HTML`

*   **Null Avhengigheiter** - Alle innhaldsressursar er innebygde i ei enkelt
    super `HTML`-fil som kan køyrast kvar som helst med ein fungerande
    nettlesar.
*   **`PDF` Output Assistanse** - Ver klar til å konvertera "Super `HTML`"
    til `PDF` ved hjelp av headless browser trykkproduksjon (Merk: du må ha
    med di eiga trykksamsvarande `CSS` stilsett).
