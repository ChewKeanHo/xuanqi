[![XuanQi](src/icons/animated-banner_1200x200.svg)](#)

Dependency hell; too many build processes; constant updates;
brittle frameworks and workspaces; security nightmares;
unmaintainable time bombs at scale; and geopolitical instability
troubling your content production system? Don't let them hamper

**XuanQi - Just Build The Contents Seamlessly!**




## Why It Matters

[![XuanQi](src/icons/animated-banner_1200x100.svg)](#)

This project was initiated primarily because of:

1. **Controls Is Always Yours** - No "after-the-fact" mercenaric terms
   and conditions and business policy changes.
2. **Maintain High Customizability** - Contents are built programmatically
   instead of getting troubled with all kinds of abstractive assumptions and
   vendor locked-in processes.
3. **Decentralized Supply Chains** - Be completely free from geo-politic
   nuisances and idiocracy.
4. **Maintain High Modularity** - Simple enough to manage all kinds of external
   components and resources built from various technologies.
5. **Reliable Reproducibility** - Re-produce content reliably anywhere anytime
   be it single file `.pdf`, entire static pages website, web page, images, etc.
6. **Very Low Learning Cost** - Re-use your shell scripting knowledge
   (POSIX Shell and PowerShell). No specific programming language required.
7. **Simple to integrate** - 1 simple command enough to be integrated with any
   CI.




## Key Features

[![XuanQi](src/icons/animated-banner_1200x100.svg)](#)

XuanQi is currently capable to handle various content generations related
tasks. Let's check the out!



### Static Site Generation (SSG)

* **Use The Entire Repository** - No need to pre-duplicate assets and resources
  just to please a SSG generator's nuisance limitations.
* **Seamlessly Output Structure** - Map the entire sites with just that simple
  OS filesystem file pathing with No complicated or proprietary database
  parsing.
* **Extremely High Customizability** - Each file is processed by its own shell
  script so you make the production call freely.
* **No Output Restrictions** - No internal SSG generator restrictive nonsense so
  you and your publication provider decide what to produce.
* **No Jack-of-All-Trades Sub-par Quality "Features"** - Just integrate and use
  the dedicated tools directly like GIMP for image processing and FFMPEG for
  audio and video processing.
* **Search Engine Optimization (SEO) Assistances** - Readily to comply the SEO
  requirements with XuanQi's optional SEO assistances functions.
* **Progressive Web App (PWA) Assistances** - Readily to transform your website
  into a PWA web app easily using XuanQi's optional PWA assistances functions.
* **WASM Assistances** - Readily to embed or to integrate WASM into your
  "Super HTML" using XuanQi's WASM optional integration functions.



### Super HTML

* **No Dependencies** - Everything is embedded into 1 single super HTML
  operable anywhere anytime with a working browser.
* **PDF Output Assistances** - Readily to convert into PDF using headless
  browser print production (NOTE: you bring your own print compliant CSS
  stylesheet).
